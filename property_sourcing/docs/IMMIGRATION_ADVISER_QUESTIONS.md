# Questions for an OISC-registered immigration adviser / immigration solicitor

**Purpose of this document:** a short, specific list to take into a paid
advice session, so the conversation is quick and cheap rather than a full
"can I run a business" review (the answer to that is already known: not yet,
on a Skilled Worker visa, without a status change — see
[`LAUNCH_CHECKLIST.md`](LAUNCH_CHECKLIST.md)). These are the genuinely
ambiguous edge cases worth paying for a clear answer on.

**Context to give the adviser up front**, so they understand what's actually
built (give them this paragraph, or forward this whole file):

> I'm on a Skilled Worker visa. As a personal coding project, I've built (but
> not operated) two pieces of software: (1) a tool that would, if run for
> real, find below-market-value UK properties from public data sources and
> introduce them to cash buyers/investors for a one-off fee, and (2) a tool
> that would match prospective tenants to rental listings and introduce them
> to landlords for a commission paid by the landlord only. Neither has ever
> contacted a real seller, landlord, tenant, or investor, taken a payment, or
> been advertised — it only runs against fictional demo data I made up. I
> I want to understand exactly where the line is before I'd need a different
> visa status, without assuming more than I need to.

## Questions

1. **Open-sourcing or giving away the code itself, for free, with no users
   paying me anything** — is that self-employment or running a business in
   any sense, or is it unambiguously just a hobby/portfolio activity
   regardless of how "commercial" the code's intended purpose looks?

2. **Personal property investment using tools I built myself** — if I
   personally buy a single buy-to-let property (as an individual landlord,
   not through a company) and find/evaluate it using software I wrote, does
   that count as self-employment, or is it treated as passive investment
   income the same way it would be if I'd found the property on Rightmove
   myself? Does the answer change if I also use the tenant-matching tool to
   find my own tenant, rather than going through a letting agent?

3. **Threshold between "project" and "business"** — is there a specific,
   named test (e.g. "any exchange of money," "any member of the public
   other than me," "any repeated/regular activity") that UK immigration
   rules or case law actually use to decide if an activity counts as
   self-employment for a Skilled Worker visa holder? I want a concrete rule
   I can self-check against going forward, not just "it depends."

4. **A legally eligible partner operating the business, with my involvement
   limited to unpaid software maintenance** — if a friend or family member
   who is a UK citizen/ILR holder set this up as their own sole trader
   business, used the software I continue to maintain for free, and I had
   no ownership stake, no pay, and no role in client-facing decisions, is
   that arrangement actually safe under my visa conditions, or is it the
   kind of structure that gets scrutinised regardless of how it's framed?
   What specific facts would make it unsafe (e.g. me ever emailing a client
   directly, me being named on any contract, me receiving any payment even
   informally)?

5. **Freelance/contract software development for an unrelated client** — if,
   separately from this project, I were offered paid freelance work writing
   similar software for someone else's property business (not operating the
   business myself, just being paid to build the tool), would that require
   a different visa route, or does my Certificate of Sponsorship/employer
   permission already cover any outside paid work in any circumstance?

6. **What changes the day my status changes** — assuming I later get ILR,
   switch to an Innovator Founder visa, or another route that permits
   self-employment, is there anything about *having already built and
   privately tested this software* that could complicate that transition or
   needs to be disclosed/handled carefully (e.g. in an Innovator Founder visa
   business plan or ILR application), or is "I built and tested software in
   my spare time, generating no income" simply a non-issue to mention?

## What NOT to ask (already answered, don't pay for this again)
- "Can I run this as a business right now?" — No, confirmed, not on a
  Skilled Worker visa without a status change.
- "What regulatory registrations does a UK property sourcer/letting agent
  need?" — Already researched in
  [`LEGAL_COMPLIANCE.md`](LEGAL_COMPLIANCE.md) and
  [`LETTINGS_LEGAL_COMPLIANCE.md`](LETTINGS_LEGAL_COMPLIANCE.md); this is a
  separate (business/regulatory) question from the immigration-status
  question above, and doesn't need an immigration adviser specifically.

append them to this file or to `LAUNCH_CHECKLIST.md` — so future-you (or
whoever picks this project up) doesn't have to re-ask or guess what was
already cleared.
